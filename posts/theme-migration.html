这个博客已经是第三代了。趁刚搬完家，把三次的经历整理一下，也算是给未来的自己留个记录。

一代目：手写静态页 ​

最早的版本是纯 HTML + CSS 手写的，一个页面一个文件，改个导航要动五个文件。

现在回头看确实简陋，但那种"每个像素都是自己挪的"的成就感，后来用什么主题都找不回来。代码写得丑，不过里面放的内容都是认真的。

二代目：Astro + Mizuki ​

后来换成了 Astro 的 Mizuki 主题。粉粉的，功能也全：搜索、评论、RSS、暗色模式都有，用了挺长时间。

换掉它的理由说出来有点任性——我就是想要个蓝色的站点。颜色这种东西，看久了真的会腻。

三代目：VitePress 魔改主题（现在） ​

就是你现在看到的这个。

三代目技术清单

  • 框架：VitePress 1.6 + Vue 3，页面切换是 SPA 式的，很顺滑
  • 主题：在一个开源游戏风主题的基础上自己改的，蓝色为主，配色和图标都换过了
  • 看板娘：Live2D 模型 Shizuku，亮色模式穿常服，暗色模式换睡衣，视线会跟着鼠标走，点她会有反应
  • 点击特效：屏幕上点击会出现小图案（可以在右上角菜单开关）
  • 字体：霞鹜文楷 Screen，按 unicode 分包按需加载，不拖速度
  • 背景音乐：用 Python 的 wave 模块合成的 8-bit 小曲，原创无版权问题
  • 搜索：Minisearch 全站全文搜索
  • 评论：giscus，用 GitHub 账号登录就能发言
  • 部署：GitHub Pages，源码开源在仓库里

过程中踩的坑 ​

  1. Live2D 模型自托管：网上教程基本都是甩一个 CDN 链接完事。为了不被第三方 CDN 连累，我把 pixi.js、Cubism2 核心和模型文件共 111 个文件全部放进了站点里，5MB 出头，换来的稳定性是值得的。
  2. base 路径问题：站点部署在 /LQY/ 子路径下，所有绝对路径都要注意前缀。看板娘组件里漏写一个前缀，模型就直接 404。
  3. 背景音乐：原本想找现成的无版权曲子，找了一圈都不合适，最后干脆自己用方波和三角波合成了一首。Python 的 wave 模块意外地好用。

以后想加的功能 ​

  • [ ] 文章阅读时间估计
  • [ ] 标签页的筛选优化
  • [ ] 相册页（存点自己拍的照片）

总之，欢迎来到第三代。

搬家这件事大概一时半会儿停不下来，不过下次再动手之前，我会先看看月考日程表的。
