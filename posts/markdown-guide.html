Markdown 排版指南：本站支持的全部写法

2026 年 9 月12 日 指南 约 6 分钟 更新于 2026 年 9 月13 日
#Markdown#写作#排版

这篇文章是本站的排版样张。所有常见的 Markdown 语法都在这里跑了一遍，改版之后可以直接打开这一页检查有没有哪里崩掉。

标题与层级

正文里只用两级标题：h2 是章节，h3 是小节。右侧目录会自动抓取它们，并在滚动时高亮当前所在的位置。

字号与节奏

中文正文的行高设在 1.95，比英文排版更松一些——方块字需要更多的呼吸空间。段落之间的间距是 1em，不加首行缩进，因为屏幕阅读和首行缩进本来就不太合得来。

强调与行内标记

你可以用 粗体 强调重点，用 斜体 表示语气，用 高亮 标出结论。行内代码写成 terminal --help 这样。链接 会带一条淡色下划线，鼠标移上去颜色加深。

需要引用别人的话时，可以用脚注式的括号说明（比如“徒劳”这个词，川端康成用了一辈子）。

列表

无序列表适合罗列并列的东西：

  • 春：樱花、梅雨、第一声蝉鸣
  • 夏：冰镇西瓜、风扇、午后漫长的白
  • 秋：银杏、晒被子的味道、变短的白天

有序列表适合写步骤或序列：

  1. 新建文章文件，放在 posts/ 目录下；
  2. 在数据文件里补一条记录；
  3. 重新生成页面；
  4. 提交并推送。

引用

国境の長いトンネルを抜けると雪国であった。
夜の底が白くなった。

引用块左侧有一条主色描边，背景用色调更浅的容器色，和正文区分开但不抢眼。

代码

行内代码用等宽字体加浅色底。成块的代码放在深色卡片里，长行会自动横向滚动：

# 换主题色只要改一个数字
:root {
  --h: 315;   /* 315 = 樱粉，265 = 紫罗兰，205 = 青空 */
}

/* M3 色调体系：其他颜色都从它推导 */
.m3-card {
  background: var(--surface-container-low);
  border-radius: var(--shape-corner-l);
}

表格

色相名字适合的气质
315樱粉柔和、偏二次元（本站默认）
265紫罗兰安静、偏文学
205青空清冷、偏科技
160薄荷清爽、偏自然
30暖橘温暖、偏生活记录

提示框

说明

默认的提示框用来补充背景信息，不打断阅读节奏。

建议

长文章结尾放一句能被单独摘出来的话，读者更容易记住。

注意

提示框一次不要用太多，超过两三个就会变成视觉噪音。
