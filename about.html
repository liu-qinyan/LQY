你好，这里是柳卿烟 ​

一名高二学生，坐标某个夏天很热、冬天很冷的城市。

白天的课表是数学、物理、英语轮番上场；放学之后的时间属于自己——看动画、打游戏、听歌，偶尔折腾一下这个网站。

概括一下：在题海和课余爱好之间找平衡，两边都不想放弃。

兴趣爱好 ​

  • 动画：每季追 3-5 部，习惯三集定去留，观后感会发在站里
  • 游戏：QQ 飞车玩了挺久，偶尔怀旧一下小学的网页游戏
  • 喜欢的画师：甘城なつき（Nachoneko），她的原创角色猫羽雫是我用了很久的壁纸来源
  • 音乐：歌单按心情分类，公交上的 23 分钟必须有 BGM
  • 瞎折腾：HTML/CSS/Python 三脚猫水平，最大的成果就是这个站

本站简史 ​

时期形态
一代目手写静态页，纯 HTML+CSS，丑但真诚
二代目Astro + Mizuki 主题
三代目VitePress 魔改主题，现在这个样子

域名用的是 GitHub Pages（liu-qinyan.github.io/LQY），托管在 GitHub 上，全部源码也在同一个仓库里。看板娘、点击特效、背景音乐都是自己动手改的，欢迎右键查看源码。

一些问答 ​

Q：为什么主题是蓝色的？ A：个人喜好。蓝色看着舒服，配色、图标、看板娘都是照这个方向搭的。

Q：为什么不太玩手游了？ A：玩过，后来发现自己更喜欢"上车就能跑一圈"这种节奏快的游戏，单局短，不黏人，适合学生的时间表。

Q：更新的动力是？ A：评论区的每一条留言，和"又活过了一场月考"的仪式感。

Q：可以转载文章吗？ A：可以，注明作者和原文地址即可。商业用途不行。

Q：怎么联系？ A：评论区留言最快；也可以在 GitHub 提 issue。

最后 ​

如果屏幕前的你也是"白天上课、晚上有自己的小世界"的同款学生—— 平衡好学习和爱好，两边的快乐都别放弃。

月考周会断更，但小站一直都在，放学后见。
