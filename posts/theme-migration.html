猫爪特效
看板娘

发布于 1970/01/01 | 约0字

这个博客已经是第三代了。趁今天刚搬进"猫窝"，把三次搬家史整理一下，免得未来的我忘了这一路的坑。

一代目：手写静态页（纯手工时代的浪漫） ​

最早的版本是纯 HTML + CSS 手搓的，一个页面一个文件，改个导航要动五个文件。

现在回头看确实简陋，但那种"这个像素是我亲手挪的"的成就感，之后任何主题都给不了。代码丑但真诚，像个歪歪扭扭的纸箱，但里面装的东西是真的。

二代目：Astro + Mizuki（粉色的温柔） ​

后来换成了 Astro 的 Mizuki 主题。粉粉的，功能也全：搜索、评论、RSS、暗色模式什么都有。

用得挺好的。唯一的缺点是……它不是蓝色的。（这个理由自己说出来都觉得离谱，但二次元的事情，你懂的。）

三代目：VitePress + 猫窝（现在这个样子） ​

就是你现在看到的这个。

三代目技术清单

  • 框架：VitePress 1.6 + Vue 3，SPA 式的页面切换，丝滑
  • 主题：深度魔改——我把原来的游戏风主题整个拆了，换成猫羽雫元素，蓝白猫爪配色
  • 看板娘：Live2D 猫娘 Shizuku（对，名字都和雫雫的罗马音一样，这真是天意）。亮色模式穿常服，切到暗色模式会换上睡衣，鼠标移过去视线会跟着你走，点她还会说话
  • 点击特效：原来的游戏火花特效换成了猫爪印，随便点点屏幕试试
  • 字体：游戏美术字体 → 霞鹜文楷 Screen，按 unicode 分包按需加载
  • 背景音乐：→ 我用 Python 一行行合成出来的原创 8-bit 芯片音乐（对，代码写的歌）
  • 搜索：Minisearch 全站全文搜索
  • 评论：giscus，GitHub 账号登录即可发言
  • 部署：GitHub Pages，全部源码开源在仓库里

搬家过程中踩的坑（仅记录几个典型的） ​

  1. Live2D 模型自托管：网上教程基本都是甩个 CDN 链接完事。为了不被第三方 CDN 抽风连累，我把 pixi.js、Cubism2 核心、shizuku 两个形态共 111 个文件全部下到了站点里。5MB 出头，值。
  2. VitePress 的 base 路径：部署在 /LQY/ 子路径下，所有绝对路径都要小心 base 前缀。看板娘组件里漏写一个前缀，模型就 404 给你看。
  3. 音乐：原来的 BGM 是某手游的曲子，本命换了之后继续用就不合适了。找不到合适的无版权曲子，最后干脆自己用方波和三角波"画"了一首。Python 的 wave 模块是真好用。

以后还想加什么 ​

总之，欢迎来到三代目。

博客这条路，一时半会儿是折腾到头了……大概。下次再想折腾的时候，记得先看看月考日程表。
