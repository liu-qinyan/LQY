建站记：在 GitHub Pages 上安一个家

2026 年 9 月14 日 记录 约 7 分钟
#建站#GitHub Pages#静态博客

今天这个博客正式上线了。地址是 https://liu-qinyan.github.io/LQY/，一个不会变、也不需要服务器续费的固定链接。写这篇记录，是想把“为什么要这么做”和“具体怎么做的”都留下来——毕竟半年后我大概率已经忘了。

为什么是静态博客

最开始我认真考虑过用现成的博客平台：注册快、不用管运维、手机也能发。但试了一圈之后还是放弃了，理由说出来有点固执：

  • 链接会变。平台改版、内容审查、服务下线，地址就死了。我想要一个能贴在任何地方、五年后还能打开的链接。
  • 排版不属于我。字体、行高、字间距，我想按自己的眼睛来调。
  • 文章的寿命应该比平台长。静态文件放在那里，就算托管商换了，搬走也只是复制一个文件夹的事。

于是就有了现在这套方案：纯静态的 HTML + CSS + JS，托管在 GitHub Pages 上，没有后端、没有数据库、没有构建依赖。

参考了什么

视觉上主要参考了 Shirone 这个主题——一个以 Material 3 Expressive 为骨架、二次元气质的 Astro 博客主题。它有几个我很喜欢的地方：

特性我学到的东西
动态取色整站颜色由一个“色相”数字推导，改一个值就能换皮肤
平滑换页页面切换时保留外层的“世界”，只替换内容区
零负担可选功能关掉的功能不产生任何请求、DOM 和布局抖动
卡片与层次用色调层级而不是阴影来表达“浮起”

如果把博客比作一间屋子，那么主题只是装修。真正让它变成“家”的，是你往里搬的东西。

具体怎么做的

整套站点没有构建步骤，所有页面都是手写的 HTML，样式集中在一个 CSS 文件里。这样做的代价是改版时要多写一点，好处是：任何时候用浏览器打开一个 .html 文件就能看到效果，不需要装 Node、不需要等编译。

发布流程也很短：

git add .
git commit -m “post: 新的文章”
git push origin main

推送完成后，GitHub Pages 会在几十秒内自动发布。整个链路里唯一需要付费的东西是域名（如果以后要换的话），其余全是免费额度。

小提示

仓库根目录放了一个空的 .nojekyll 文件。它的作用是告诉 GitHub Pages 不要用 Jekyll 处理站点，能避免很多莫名其妙的问题（比如以下划线开头的文件被忽略）。

之后想做的

  1. 把过去写在别处的零散文字搬过来，按年份归档；
  2. 加一个真正能用的全文搜索（现在是本地索引，够用但还粗糙）；
  3. 写几篇长一点的东西——关于读过的书、看过的番、走过的路；
  4. 也许把评论打开。也可能一直关着。

如果你也想搭一个，其实不用想太多：先让它上线，再让它好看，最后让它有内容。顺序反了就永远开始不了。
